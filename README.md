## 💡 The Manifesto: Why SideQuest?

Gen Z in Indian metros is experiencing peak **digital exhaustion**:
- **Dating apps** are plagued by endless small-talk that never translates to real life.
- **Meetup apps** feel like awkward corporate networking mixers with 2-week planning cycles.
- **Group chats** suffer from the *"bro let's meet soon"* loop that perpetually ends in ghosting.

**SideQuest flips the script:**
1. **Low Stakes**: You aren't committing to a date or a lifetime friendship. You are grabbing a 20-minute cutting chai or playing 2v2 badminton right now.
2. **Self-Destructing Lobbies**: If nobody claims an open slot within 90 minutes, the Flare dissolves without a trace. Zero public embarrassment.
3. **Anti-Flake Proof of Show-Up**: On-time GPS verification rewards users with **+10 Karma XP**. Ghosting results in severe karma penalties and public flake rates.
4. **Zero-Password Frictionless Identity**: Gen Z hates long forms. Start exploring, dropping flares, and claiming open spots in 5 seconds flat with zero mandatory auth walls.

## ⚡ Key Features

### 1. 🗺️ 3D Cyberpunk Vector Radar ([OpenFreeMap + MapLibre GL])
* Hardware-accelerated 3D vector map with a 52° cinematic tilt and 3D building extrusions.
* **100% Free Forever**: Zero API keys, zero rate limits, and zero proprietary watermarks.
* **Sonar Pulse Markers**: Luminous drop nodes pulsing in real-time with category badges, open capacity counters, and a continuous 360° radar sweep cone.
* **1-Click 3D / 2D Toggle**: Switch between video-game perspective and flat tactical bird's-eye view anytime.

### 2. 🛡️ GPS Geofence & Anti-Flake Karma System
* **Haversine Geofence Engine**: Verifies physical user coordinates against the venue coordinates within a 500-meter radius.
* **Street Cred Taste Graph**: Profiles track show-up rate % (e.g. `0% Flake Rate • 100 Karma XP`).
* **Verified Check-Ins**: Confetti animation unlocks the quest scrapbook memory. Includes dev bypass for testing from any location.

### 3. ✨ AI Wingman (Icebreaker & Vibe Engine)
* Powered by **Google Gemini 1.5 Flash** with localized zero-cost fallback.
* Contextual icebreaker generator tailored to hyper-local city culture (e.g. Silk Board traffic lore, specialty pour-over debates, momo rankings).
* In-lobby **`Reroll Vibe`** button to dynamically refresh conversation starters before everyone arrives.

### 4. 🌸 Girls-Only Protected Lobbies
* Female hosts can toggle a protected state visible only to verified female profiles.
* Public-only landmark anchoring prevents unsafe or isolated venue drops.

### 5. 📲 Viral Growth & Reddit Launch Kit
* **9:16 Instagram Story Card Generator**: 1-click HTML5 Canvas export of a 1080×1920 cyberpunk card for Instagram Stories or WhatsApp Status.
* **Reddit 1-Click Launch Kit**: Detects the metro and pre-formats non-spammy, engaging launch copy for `r/bangalore`, `r/mumbai`, `r/delhi`, `r/pune`, etc., with a direct submission link.
* **WhatsApp Group Broadcast**: Instant WhatsApp deep-link with formatted invite cards.

## 🏃 Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/barshal-horse/sidequest.git
cd sidequest
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch local radar
```bash
npm run dev
```

Open [**http://localhost:3000**](http://localhost:3000) in your browser.
